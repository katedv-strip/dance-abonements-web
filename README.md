# Абонементы группы — демо

Витрина интерфейса Telegram Mini App для учёта абонементов в танцевальной группе.

**Все данные здесь выдуманы.** Имена, даты, оплаты и посещения — придуманные,
это не настоящая группа. Рабочая версия с реальными данными живёт в закрытом
репозитории и на сервере.

Открывается: https://katedv-strip.github.io/dance-abonements-web/

Вверху переключатель «Ученица / Преподаватель» — он только в демо, в Telegram
роль определяется автоматически.

## Что показывает

У ученицы: сколько времени она танцует, остаток абонемента с датой следующей
оплаты, кнопка отметки, посещаемость за месяц и за всё время, календарь занятий.

У преподавателя: журнал занятия с галочками, светофор абонементов (кому пора
платить), карточки учениц, добавление новых.

Остаток абонемента, дата окончания и дата оплаты не хранятся, а считаются из
даты оплаты и дней группы.
